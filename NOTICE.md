# Aviso y atribución

Hermes Manager for Windows es una herramienta comunitaria independiente para ejecutar instancias de [Hermes Agent](https://github.com/NousResearch/hermes-agent) mediante Docker Desktop.

No es un producto oficial de Nous Research y no está afiliado, patrocinado ni respaldado por Nous Research. Hermes Agent, sus imágenes Docker, marcas y componentes se distribuyen bajo sus propios términos y licencias. Antes de distribuir o utilizar este proyecto, revisa también la licencia y la documentación del proyecto original.

La licencia MIT incluida en este repositorio cubre únicamente el código propio de Hermes Manager for Windows. No modifica ni sustituye las licencias de Docker Desktop, Ollama, Hermes Agent, proveedores de modelos o imágenes descargadas.
